# tools.ai — The AI Tooling Reference Website

[![Python Generator](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Zero Build Dependencies](https://img.shields.io/badge/Build-Zero%20Dependencies-orange.svg)]()

**tools.ai** is a comprehensive, static, open-source reference website cataloging AI tools for working professionals. For every tool, the site explains *what it is, why it matters, who uses it, how to use it, what it costs,* and *where to go to start using it*.

---

## 🌟 Architecture & Design Principles

This site follows the zero-dependency, Python-based static generator architecture used across Joseph's reference projects (`rust.ai`, `php.ai`, `nodeJS.ai`, `machinelearning.ai`).

- **Generator:** Pure Python 3 static generator (`src/generator.py`) — zero Node.js build step, zero heavy frameworks.
- **Data Layer:** Structured, validated JSON files in `data/tools/*.json` and `data/categories.json`. Content lives separate from rendering templates.
- **Interactivity:** Vanilla JS (`assets/js/app.js`) for instant client-side multi-select filtering, live search-as-you-type, sorting, theme toggling, and copy-to-clipboard.
- **Theme:** "AI Control Room / Signal Directory" aesthetic — dark default mode, CSS custom properties, monospace metadata accents, and responsive layout.
- **Schema Validation:** Strict build-time schema validation that fails the build if required fields or pricing attributes are missing.

## 🛠️ How to Build and Run Locally

### 1. Prerequisites
- Python 3.10+ installed.

### 2. Generate the Static Site
Run the site generator from the root directory:

```bash
python3 src/generator.py
```

This validates all JSON tool files against the schema and renders the complete static website into the `dist/` directory:
- `dist/index.html` — Homepage with search, stats, featured tools, and category directory.
- `dist/directory.html` — Searchable global directory table with live filters.
- `dist/categories/` — Individual pages for all 20 categories.
- `dist/tools/` — Dedicated pages for every single tool.
- `dist/roles/` — Dedicated pages for tools grouped by professional role (e.g. Developers, Marketers).
- `dist/about.html` — Methodology and contribution documentation.

### 3. Serve the Site
Serve the `dist/` folder using Python's built-in HTTP server:

```bash
python3 -m http.server 8000 --directory dist
```

Open `http://localhost:8000` in your web browser.

## 📝 How to Add a New Tool

All tool data lives in `data/tools/<category_id>.json`. To add a new tool:

1. Locate or create the target category JSON file in `data/tools/`.
2. Add a new tool object matching the strict schema:

```json
{
  "id": "example_tool",
  "name": "Example Tool",
  "maker": "Company Name",
  "tagline": "One-sentence executive summary of capability.",
  "category": "general_chat_assistants",
  "subcategory": "conversational-ai",
  "definition": "2-3 sentences plain language definition explaining what it fundamentally is.",
  "why_it_matters": "2-4 sentences explaining its significance, market position, and impact.",
  "workplace_use_cases": [
    "Concrete workplace use case 1",
    "Concrete workplace use case 2"
  ],
  "who_uses_it": ["Software Engineers", "Marketers", "Product Managers"],
  "how_to_use": "Short practical getting-started instructions.",
  "key_features": ["Feature 1", "Feature 2", "Feature 3"],
  "pricing": {
    "model": "freemium",
    "has_free_tier": true,
    "free_tier_details": "Exact details of free tier limits.",
    "paid_plans": [
      {"name": "Pro", "price": "$20/month", "notes": "Plan features and usage limits."}
    ],
    "pricing_last_verified": "2026-03-01"
  },
  "official_url": "https://example.com",
  "logo_source_note": "Official brand asset",
  "related_tools": ["chatgpt", "claude"],
  "launched": "2024",
  "platform": ["Web", "iOS", "API"]
}
```

3. Re-run `python3 src/generator.py` to re-validate the schema and regenerate the site.
4. Submit a Pull Request on GitHub.
